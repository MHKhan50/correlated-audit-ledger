# Publishing checklist

- [ ] Run the tests and experiment locally; inspect the output CSV and summary.
- [ ] Create a GitHub repository and push the project files (do not commit secrets).
- [ ] Replace any repository placeholders in the article/site HTML with the real GitHub URL.
- [ ] Publish the article on the website and verify its public URL.
- [ ] Upload `outputs/synthetic_test_dataset.csv` to Kaggle with `outputs/dataset_card.md` and a clear synthetic-data disclaimer.
- [ ] Cite the repository and keep code/data licences visible.
- [ ] Optionally deposit a release on Zenodo for a DOI; verify metadata before publishing.
- [ ] Use Search Console URL Inspection if you want to request indexing; indexing is not guaranteed.
